# 소리나는 피드백 (Sorina Feedback)

텍스트만으로는 부족했던 피드백을 필기와 음성으로 더 생생하게 전달하는 웹 도구입니다.

## 주요 기능
- **PDF 과제 불러오기**: 학생의 PDF 과제를 업로드하여 피드백을 시작합니다.
- **인터랙티브 필기 & 녹음**: 필기를 하면 자동으로 음성이 녹음되며, 필기와 음성이 동기화됩니다.
- **학습자 모드 (뷰어)**: 학생은 링크나 파일을 통해 선생님의 피드백을 실시간 애니메이션과 함께 확인할 수 있습니다.
- **ZIP 내보내기/불러오기**: 오프라인에서도 피드백을 보관하고 공유할 수 있도록 모든 데이터를 압축 파일로 내보냅니다.

## 배포 가이드 (Deployment)

이 프로젝트는 정적 HTML/CSS/JS로 구성되어 있어 어디서든 쉽게 배포할 수 있습니다.

### 1. GitHub Pages (추천)
1. GitHub 리포지토리를 생성하고 파일을 업로드합니다.
2. `Settings` > `Pages`로 이동합니다.
3. `Branch`를 `main`으로 설정하고 `Save`를 누릅니다.
4. 잠시 후 제공되는 URL을 통해 접속 가능합니다.

### 2. Netlify / Vercel
1. 프로젝트 폴더를 해당 서비스에 드래그 앤 드롭하면 즉시 배포됩니다.

## 상용 환경 고려사항
- **데이터 저장**: 현재 버전은 별도의 서버 없이 브라우저의 `IndexedDB`와 `LocalStorage`를 사용합니다. 따라서 생성된 '공유 링크'는 해당 브라우저에서만 유효합니다.
- **영구 보관**: 다른 사람에게 공유하거나 영구적으로 보관하려면 반드시 **'피드백 파일 다운로드 (ZIP)'** 기능을 이용해 주세요.
